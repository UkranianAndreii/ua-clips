Privacy Policy — UA Clips Uploader

Last updated: 18 November 2026

UA Clips Uploader ("the app") is a private tool used by a single person, the owner of the YouTube channel @ua_twitch_clips, to upload videos to that channel, and to send the same videos as drafts to the owner's own TikTok account.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

TikTok

The app uses TikTok Login Kit and the Content Posting API (upload to inbox) with the scopes user.info.basic and video.upload, only for the owner's own TikTok account. Videos arrive in the owner's TikTok inbox as drafts; the owner reviews and publishes them manually in the TikTok app. The app does not read or store data about other TikTok users. See the TikTok Privacy Policy. Access can be revoked in the TikTok app: Settings and privacy → Security → Apps and services permissions.

What data the app accesses

  • The OAuth 2.0 scope youtube.upload, used only to upload videos to the owner's own channel.
  • The app does not read, collect or store any data about other YouTube users, viewers, comments, subscribers or analytics.

What is stored and where

  • The OAuth access/refresh tokens (Google and TikTok) are stored only on the owner's own computer in a file readable by the owner alone. It is never shared or transmitted anywhere except to Google's and TikTok's OAuth and API endpoints.
  • No YouTube or TikTok API data is stored, sold or shared with third parties.
  • Speech transcripts of public Twitch stream fragments (not YouTube data) are sent to a language-model service to suggest a title and description for the clip before upload.

Revoking access

Access can be revoked at any time at Google security settings. Deleting the local token file also removes the app's access.
