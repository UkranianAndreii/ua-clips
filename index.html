UA Clips Uploader

UA Clips Uploader is a private, single-user tool that publishes short highlight clips to one YouTube channel, UA Твіч Кліпи (@ua_twitch_clips), a fan channel about Ukrainian Twitch streams.

What it does

  1. Detects notable moments in public Ukrainian Twitch streams and prepares a vertical clip with Ukrainian subtitles.
  2. Sends the clip to the channel owner for review in a private Telegram chat.
  3. Only when the owner approves a clip, uploads it to the owner's own channel with the YouTube Data API (videos.insert).

Who uses it

Only the channel owner. It is not offered to other users, has no sign-up and no public interface. It signs in with OAuth 2.0 using only the https://www.googleapis.com/auth/youtube.upload scope.

Every video credits the streamer with a link to their Twitch channel.
